02 · Core Topic

What is ElGamal Cryptosystem?

ElGamal is a public-key encryption scheme based on the mathematical difficulty of the discrete logarithm problem. It uses a public key for encryption and a corresponding private key for decryption.

03 · Process

ElGamal Workflow

Generate Keys

Choose public parameters and create the private/public key pair.

Prepare Message

Represent the plaintext as an integer in the valid modular range.

Encrypt

Generate a fresh random ephemeral key k and produce the ciphertext pair (c₁, c₂).

Transmit

Send the ciphertext through an untrusted channel while keeping the private key secret.

Decrypt

Use the private key to reconstruct the shared value and recover the plaintext.

Important Security Note

Real cryptographic software must use carefully reviewed libraries, secure random number generation, suitable parameter sizes, authenticated encryption where appropriate, and expert-reviewed protocols. Small classroom numbers are for learning only.
